# 银杏寄语 · Leaf

一棵会替你留一句话的银杏树。

夕阳、蓝天、风里翻飞的金色叶片、地上厚厚的落叶毯子。**打开就是一片安静的秋天**：
没有弹窗、没有面板，只有树和风。想说话的时候，点底部那一行「写一句话」。

写完后，树冠会卷起一阵金色的风，叶子在天空里旋成一盘缓慢的银盘，树上挂起一块
竖排写着那句话的木牌。**那句话会被写进网址里**——把链接发过去，对方打开时，
整棵树、那句话和那阵风都已就绪。谁写给谁都可以，不预设表白。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出 dist/，丢到任意静态托管即可
```

## 怎么用

1. 默认就是**沉浸模式**：只有画面。点「写一句话」展开卡片。
2. 填上 TA 的名字，写一句想说的话，点「把这句话交给银杏树」→ 立刻回到纯画面，落叶旋舞，木牌挂上。
3. 底部「把这片叶子发给 TA」→ 系统分享 / 复制带话的链接（微信、QQ 直接粘就行）。
4. 对方打开链接，页面自动演一遍。

其它小心思：

- **Esc** 或右上「沉浸」随时回到纯画面。
- **移动鼠标**：指针附近的叶子会像被风拨开一样让开，掠过枝头带起细碎沙沙声。
- **轻点树冠**：下一场局部金色骤雨。
- **拖动**换角度，**滚轮 / 双指**远近，镜头自己缓慢环绕。
- **声音**：第一次点画面即自动开启（浏览器要求用户手势）。右上小喇叭可随时关。
- 手机竖屏自动换构图、隐藏无用的 Esc 提示、关阴影、减半叶片。

## 声音怎么做的

全部 Web Audio 实时合成，**没有任何音频文件**：

- 粉红噪声（1/f）作底，分四层：空气的低频体积、穿过树冠的中频、枝条的窄带呼啸、叶片的高频干响。
- 超低频 LFO 让风"呼吸"；每 1.9 秒各层频率与声像缓慢漂移；每 5–13 秒来一次真的阵风
  （窄带共振扫频 + 声像移动），所以不会是一成不变的白噪声。
- 户外卷积混响（早期反射 + 软尾）+ 总线限幅器。
- 落叶声不是一次「唰」，而是十几个随机音高、随机声像、随机时长的微小颗粒。
- 许愿铃是三音上行的 FM 铃 + 木质敲击 + 混响。

## 技术

- Three.js + React Three Fiber + drei + postprocessing，Vite + TypeScript。
- 树是**程序化生成**的：递归分枝 + 固定随机种子，同一棵树永远长成同一个样子。
- 叶子是自定义的**银杏扇形几何体**（中央缺刻 + 后卷），叶脉、树皮、地面落叶全部 Canvas 现画。
- 所有叶子共用一套 **InstancedMesh + 自定义着色器**：顶点着色器里被风吹动、指针涡流让叶子绕开光标、
  片元着色器里加**背光透射**，逆光时叶片从内部透出金色。
- 天空手写着色器（渐变 + 太阳盘 + 光晕 + fbm 云 + dithering），地面低频起伏。
- 后期：Bloom + GodRays 光柱 + 景深 + 胶片颗粒 + 暗角 + 轻微调色。
- `PerformanceMonitor` 动态调 DPR；移动端自动降级。

## 目录

```
src/
  lib/ginkgo.ts       银杏叶几何体、叶片/树皮/地面/木牌贴图、随机数
  lib/tree.ts         程序化树结构 + 枝干合并成一个 draw call
  lib/leafMaterial.ts 共享的叶子材质（风、透光、指针涡流）
  lib/wind.ts         全局风场（树冠、落叶、尘埃共用）
  lib/audio.ts        Web Audio 风声 / 沙沙声 / 铃声
  lib/sceneState.ts   跨 DOM 与 3D 的可变状态（许愿、点击）
  scene/              Sky / Ground / Tree / FallingLeaves / Motes / LeafSwirl / LeafField / Tag / Effects
  ui/Overlay.tsx      沉浸层与交互层
```
